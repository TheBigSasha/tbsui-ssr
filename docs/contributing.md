# Contributing

Thank you for your interest in contributing to the tbsui-ssr project! This document outlines the guidelines for contributing to the project.

## Getting Started

1.  Fork the repository.
2.  Clone your fork to your local machine.
3.  Install the dependencies with `pnpm install`.
4.  Create a new branch for your changes.

## Development

*   Run the development server with `pnpm dev`.
*   Run the tests with `pnpm test`.
*   Run Storybook with `pnpm storybook`.

## Pull Requests

*   Before submitting a pull request, please ensure that your changes are well-tested and that the tests pass.
*   Please also ensure that your code is well-formatted and that it follows the project's coding style.
*   Please provide a clear and descriptive title and description for your pull request.
